# Benchmark label sets

`primary_source_labels.v1.json` is the default production-oriented label set.

- Cohort: 25 public companies.
- Scope: 125 objective labels across five fields.
- Evidence: 25 current annual Form 10-K filings and 25 official company sites.
- Review date: 2026-08-18.
- Review status: one primary-source desk review, appropriate for this portfolio engineering
  baseline. Independent review is an optional governance upgrade if the benchmark is ever used
  for consequential release decisions.

The label file is generated by `scripts/build_primary_source_labels.py`. Do not hand-edit the
materialized JSON without applying the same change to the generator. Values that cannot satisfy
the documented evidence and scoring policy remain excluded. Reviewed values live in the generator
independently from `fixtures/companies.json`, so demo-fixture edits cannot silently alter expected
benchmark answers.
